5.1서론

서론 — 대기는 왜 생기나

p.2
  • 변동성으로 인해 나타나는 결과 중 하나는 대기 (대기행렬) 문제 — 고객 입장에서는 불편함
  • 대기 시간은 보통 한정된 시간 동안 예측된 수요량이 예측된 공급량을 넘어설 때 발생 (수요가 계절적이고 공급 수준이 일정할 때)
  • 변동성 때문에 활용률이 100%가 되지 않더라도 대기행렬이 생길 수 있음 — 충분한 공급 능력이 있어도
  • 대기시간의 원인이 공급능력이냐 변동성이냐를 파악하는 것이 운영관리자에게 중요
  • 목표는 변동성을 완전히 없애는 것이 아니라, 변동성이 만드는 대기·손실 비용을 감당 가능한 수준으로 줄이는 것

5.2변동성과 프로세스

변동성의 원인과 측정 방법

p.3
원인설명버스 비유
① 입력 (도착, 수요)으로 인한 변동성가장 영향력 있는 원인은 시장버스가 늦게 와서
② 작업 (처리) 시간의 변동성기계가 아닌 사람이 작업하기 때문버스가 도중에 막혀서
③ 자원의 무작위적 가용성제조 상황에서 자원을 쓸 수 없게 될 때버스가 고장이 나서
④ 복수의 흐름 단위가 존재하는 프로세스 (흐름단위 경로)의 무작위적 경로 결정각 작업의 도착 프로세스가 영향을 받음다른 버스를 타서

변동성은 상대적으로 판단하는 것이 낫다 → 변동계수 (coefficient of variation)

\[CV = \frac{\text{표준편차}}{\text{평균}}\]
왜 상대적?표준편차 2분은 평균 4분짜리 상담엔 크지만 평균 2시간짜리 수술엔 작아요. 평균으로 나누면 비교가 가능해져요.

도착 프로세스 · 지수 분포 기반의 도착 간격

p.4 – 5
  • 분석의 품질은 사용하는 정보에 의해 결정 → 수요를 정확하게 제시해야 함. 도착시간·도착간격을 기록 후 계산
  • 모델 예측력 향상을 위한 2가지 질문: 도착 프로세스가 고정적(stationary)인가? 포아송 프로세스를 형성하는가?

도착 간격이 무작위이고 지수 분포를 따르면 (a = 평균 도착 간격):

\[P(T \le t) = 1 - e^{-t/a}\]
  • 도착 간격이 지수분포 → 포아송 프로세스 활용 가능
  • 지수 분포의 표준 편차 값은 평균과 같다
  • 지수 분포는 무기억성 (memoryless)이다 — 다음 시간 간격 동안의 도착 수는 최근의 도착 시간과 상관이 없음
\[P(T>t+s \mid T>t) = \frac{P(T>t+s)}{P(T>t)} = \frac{e^{-(t+s)/a}}{e^{-t/a}} = e^{-s/a} = P(T>s)\]
  • 평균 = 표준편차 → 변동계수는 1 : \(CV_a = \dfrac{\text{도착 간격의 표준편차}}{\text{평균 도착 간격}} = 1\)

콜센터의 문제점

p.6

통화당 평균 p = 4분, 평균 a = 5분마다 전화 1통, 직원 1명. 평균만 보면 대기는 전혀 없어야 한다?

  • 처리 능력: 60/4 = 15 통/시간, 실제 수요: 60/5 = 12 통/시간
\[\text{활용률}(u) = \frac{\text{수요율}}{\text{공급능력}} = \frac{12\text{통/시간}}{15\text{통/시간}} = 80\%\]
  • 공급 능력이 수요를 초과 → 그런데도 고객의 전화가 일정하게 걸려오지 않기 때문에 대기가 생김
  • 매니저가 관심 가져야 할 세 가지 성과 측정치: 재고 (I), 흐름율 (R), 체류시간 또는 흐름시간 (T)

서비스 시간의 변동성과 평균대기시간의 예측

p.7 – 8
  • 서비스 시간의 분포를 모델화하지 않고, 평균과 표준편차가 필요한 정보를 제공한다고 가정
  • 공급능력 > 수요, 모든 고객 수용 → 수요제약 시스템, 흐름율 R = 수요율
\[\text{자원활용률}(u) = \frac{\text{흐름율}}{\text{공급능력}} = \frac{1/a}{1/p} = \frac{p}{a} \;<\; 100\%\]
\[T = T_q + p\]
\[T_q = \underbrace{p}_{\text{서비스 시간}} \times \underbrace{\frac{u}{1-u}}_{\text{활용률}} \times \underbrace{\frac{CV_a^2 + CV_p^2}{2}}_{\text{변동성}}\]

대기시간을 만드는 3가지 요인

  • 대기시간은 서비스 시간의 몇 배수로 나타나지만, 서비스 시간은 활용률에도 영향을 미침
  • 활용률이 100% 이상이면 대기행렬은 계속 늘어남 → 100% 미만이어야 함 (u → 1 이면 u/(1−u) → ∞)
  • CVa 와 CVp 는 평균 서비스 시간 p 나 활용률 u 에 영향을 주지 않음

시사점 (장기 평균값)

  • 시스템이 빈 상태로 시작하면 첫 몇 명은 대기시간이 없다
  • 오래 관찰하면 예상대기시간 Tq 는 실증적 평균에 다가간다
콜센터에 대입CVa = CVp = 1 이라고 가정하면 \(T_q = 4 \times \frac{0.8}{0.2} \times 1 = 16\)분, \(T = 20\)분. 평균만 보면 0 이었는데!

리틀의 법칙으로 재고 계산

p.9
\[I = R \times T = \frac{1}{a}\,(T_q + p)\]
\[I_q = \frac{1}{a}\, T_q \qquad\text{(대기 중인 평균 고객 수)}\]
\[I_p = (1-u)\times 0 + u \times 1 = u \qquad\text{(서비스 받는 중인 고객 수, 서버 1명)}\]
확인\(I = I_q + I_p\) : \(\frac{T_q}{a} + \frac{p}{a} = I_q + u\). 콜센터 예 (Tq = 16): Iq = 16/5 = 3.2명, Ip = 0.8명, I = 4명.

직원 수에 대한 계획 · 우선순위 규칙

p.10 – 11

직원 수 계획

  • 상담원을 늘리면 대기는 줄지만 임금 증가 → 두 비용의 균형: 대기 비용 (고객 통화 비용·불만) vs 서비스 비용 (상담원 수)
  • 추가 비용: 통화중 신호만 듣는 고객, 기다리다 끊은 고객 관련 비용
  • 비고정적 도착 → 시간대를 몇 개 간격으로 나눌지 결정 필요: 도착률을 신뢰할 수 있게 예측할 데이터 확보 vs 대기행렬이 평형 상태가 되기엔 많은 시간이 필요
  • 휴식 시간·근무 시간의 길이 때문에 더 복잡해질 수 있음

우선순위 규칙

대기행렬을 완전히 없앨 수 없으므로 어떤 순서로 서비스할지 결정.

규칙내용
최단 프로세싱 시간 (SPT)서비스 시간을 미리 알 수 있을 때. 대기 중 가장 짧은 고객 먼저 → 일반적으로 가장 짧은 평균 체류 시간
선착순 (FCFS)가장 먼저 도착한 고객 먼저
중요도 우선응급실
SPT 가 왜 짧아?4분, 1분 고객이 대기 중이면 FCFS: 체류 4, 5 → 평균 4.5 / SPT: 1, 5 → 평균 3. 짧은 일이 긴 일 뒤에서 기다리지 않게 돼요.

변동성의 감소

p.12 – 13

도착 변동성

  • 약속(예약) 시스템: 서비스율에 맞춰 고객이 오도록 → 하지만 변동성을 없애지는 못하고, 공급 능력 대비 받을 예약 수를 판단해야 함
  • 피크를 피하는 고객에게 혜택: 영화관 조조할인, 호텔 비수기 할인, 항공사 예약 현황에 따른 가격 → 변동성을 줄이진 않지만 예측된 수요를 조정해 주기성을 줄임

서비스 시간 변동성

  • 일관된 프로세스, 개별 고객 특성 파악 · 한정된 자원에 의한 영향력 감소 · 서비스 시간 변동성은 품질 문제를 일으키는 경우가 많음
고려사항

수요의 계절성 반영 · 유휴 시간의 활용 · 자원 풀링을 통한 공급 능력 강화 · 변동성의 축소 · 우선순위 규칙

풀링 효과

p.14
  • 대기행렬을 하나로 합치고 서버를 복수 개 두면 평균 대기시간이 줄어듦. 여러 자원 (m) 을 하나로 합치는 것 = 풀링 (Pooling)
\[T_q \approx \frac{p}{m} \times \frac{u^{\sqrt{2(m+1)}-1}}{1-u} \times \frac{CV_a^2 + CV_p^2}{2}\]

은행 직원 2명, 각 줄 평균 도착 간격 4분 (CV = 1), 서비스 p = 3분 (CV = 1). 활용률 u = 3/4 = 0.75.

줄 2개 따로

\[T_q = 3 \times \frac{0.75}{1-0.75} \times \frac{1+1}{2} = 9.00\text{분}\]

한 줄로 풀링 (m = 2, a = 2분)

\[T_q = \frac{3}{2} \times \frac{0.75^{\sqrt{6}-1}}{1-0.75} \times \frac{1+1}{2} = 3.95\text{분}\]

위젯의 bank1 / bank2 프리셋으로 9.00 → 3.95 를 직접 확인해 보세요 (위 대기시간 계산기).

5.3변동성의 영향

평균값의 함정

p.15
  • 호떡 포장마차: 평균 수요 5분에 1개, 공급 능력 5분에 0 ~ 2개 → 평균은 같아도 변동성 때문에 수요가 많을 때도, 공급이 못 따라갈 때도 있음
  • 팔려면 수요와 공급이 동시에 발생해야 함 → 호떡을 미리 만들어 저장 (재고 = 버퍼) 했다가 수요가 많을 때 판매

단일 자원 대기행렬의 산출 손실 · 대기 포기 고객

p.16 – 18

병원 예시 (버퍼 없음)

  • 환자는 3개 병실 중 한 곳으로, 평균 2시간 진단 → 입원 / 심각하면 수술실. 지연되면 안 되므로 빈자리가 있는 병원으로 응급차를 우회 → 이 구조는 버퍼를 가지지 않음
  • 평균 3시간에 1명 도착, 나가는 데 평균 2시간
\[\text{공급능력} = \frac{\text{자원의 수}}{\text{서비스 시간}} = \frac{3}{2} = \text{시간당 } 1.5\text{ 환자}\]
  • 가장 중요한 단계: 프로세스에 m명의 환자가 있을 확률 (= m개의 모든 서버가 바쁠 확률 → 그때 오는 환자는 손실)
  • 이 확률은 두 변수로 결정: 함축된 활용률 \(u = \dfrac{\text{수요율}}{\text{공급능력}}\) (손실이 있으면 공급능력 > 수요 조건이 필요 없음, 1 이상도 가능) 과 자원의 수 m
숫자로 보면수요율 1/3, 공급능력 1.5 → 함축된 활용률 u = 0.222. (참고: 얼랑 손실 공식으로 계산하면 세 병실이 모두 찰 확률은 약 2.5%.)

대기 포기 고객의 산출 손실

대기할 수 있는 고객 수에 제한이 있는 버퍼: 최대 대기 통화 수가 정해진 콜센터, Drive through 음식점. 대책 3가지:

대기시간 단축공급능력의 정확한 계획, 변동성의 감소
버퍼 용량 증가버퍼 변경, 공간 확보
대기 포기 고객 감소원만한 분위기, 중요한 정보 제공, 예상 대기 시간 공개 → 기다림이 지루하지 않게

복합적인 변동성 관리

p.19
  • 공장 조립 라인, 공항 입국 심사 같은 복잡한 시스템은 단일 서버와 차이가 큼
  • 연속된 작업의 서버가 독립적이지 않음: 앞 서버에서 떠나는 프로세스 = 다음 서버에 도착하는 프로세스 → 뒤로 갈수록 앞 서버의 변동성이 중첩
  • 따라서 흐름율을 높일 잠재력을 가진 버퍼를 적극 활용하는 것이 중요

5.4 요약

p.20
  • 변동성은 모든 프로세스에 내재, 각 단계의 변동성은 동일하지 않음
  • 한 곳의 변동성 증가도 전체 산출량, 재고, 사이클 타임, 고객 서비스에 영향 → 서비스 품질 저하
  • 대응 규칙: 리틀의 법칙으로 평균대기 시간 예측 · 직원 수 계획 · 우선순위 규칙으로 체류시간 조정 · 버퍼 또는 예약 시스템

Self-check

p = 4분, a = 5분이면 활용률은? 평균만 보면 대기가 있어야 하나?
u = 4/5 = 80%. 평균만 보면 대기 없음 — 하지만 도착·서비스의 변동성 때문에 대기가 생김.
지수분포 도착 간격의 CV 는? 그 이유는?
1. 지수분포는 표준편차 = 평균이라서.
u 가 0.8 → 0.9 로 오르면 u/(1−u) 는 몇 배?
4 → 9, 2.25배. 활용률이 높을수록 대기가 폭발적으로 증가.
a = 5, Tq = 16 이면 Iq 와 I 는? (p = 4)
Iq = 16/5 = 3.2, I = (16+4)/5 = 4.
은행 예에서 풀링 전·후 Tq 는?
9.00분 → 3.95분.
