part 1입지선택의 개요

입지선택 · 입지선택의 중요성

p.2 – 3

입지선택

  • 기업의 가치를 발생시키는 요소들의 지리적 위치를 결정하는 프로세스
  • 기업의 장기 전략계획 수립에서 핵심요소 중 하나
  • 입지결정 신생기업의 일회성 의사결정 사항
    • → But 기존기업의 사업확장 시 중요 의사결정 사항

입지선택의 중요성

  • 수요의 불확실성 하에서 기업의 장기적인 대량 자본투자
    • → 기업의 중·장기 의사결정 정책에 영향
  • 입지선택은 생산용량(능력), 설비배치, 생산시스템, 물류시스템, 고용 및 지역경제에 파급효과 등에 영향
  • 생산비용 및 제품원가 결정에 영향
    • → 경쟁사와의 경쟁우위확보에 영향

입지선택 영향요인

p.4 – 5
  • 기업의 목표 달성을 위해 주요 입지결정 요인의 파급 영향력이 커야 한다.
  • 주요 입지결정 요인이 입지에 따라 기업 이익에 있어서 민감도가 커야 한다.

주요 요인과 부수적 요인으로 구분

주요 입지요인

  • 우선경쟁역량(원가, 품질, 시간, 유연성)에 영향을 미치는 요인들을 선택
  • 예) 현대자동차 앨라배마 생산공장 입지선택
    • → 호의적인 노동시장환경, 금전적인 인센티브

부수적 입지요인

  • 기업특성상 우선경쟁역량에 부수적으로 영향을 미치는 입지요인
  • 예) 현대자동차
    • → 자동차 제조업의 특성상 많은 부품 하청업체들과의 부품수급의 원활성 → 많은 수송비용 발생
    • → 부품 공장들과의 지리적 근접성

제조업 · 서비스업의 주요 입지요인

p.6 – 8

제조업의 주요 입지요인

  • 1) 수요자 및 시장의 근접성
    • 완제품의 수송비용 높을 때 → 시장에 근접하여 생산시설의 입지선택
      • a) 생산자 측면: 수송비용 vs. 완제품의 부피 및 중량
      • b) 시장 측면: 수송비용 vs. 유류비
  • 2) 공급자 및 자원의 근접성
    • 원자재 의존성이 높거나 원자재의 부피/중량이 많이 나가는 산업 → 공급자 근처에 입지선택
  • 3) 모기업 근접성
    • 생산공장과 모기업간의 긴밀한 의사소통 필요할 때
  • 4) 공공서비스 세금, 부동산 비용
    • 지방정부의 금융지원 및 세제 혜택

서비스업의 주요 입지요인

  • 1) 고객 근접성
    • ✓ 고객들이 얼마나 편하게 그 회사와 거래할 수 있는가를 결정하는 핵심적 요인
    • ✓ 핵심은 해당 시설을 자주 찾는 고객과의 근접성
  • 2) 경쟁자의 입지
    • ✓ 일반적으로 경쟁자의 입지가 확고한 지역과 동일한 지역에 입지를 선택하지 않음
    • ✓ 경쟁자와 비슷한 동종업종 동일지역 입지 → 잠재적 고객확보 가능
  • 3) 시장근접성 및 수송비용
    • ✓ 물류센터가 가까이 있으면 기업은 재고를 고객과 가까운 곳에 보유 → 인도시간 감축, 판매촉진
  • 4) 입지 특유의 요인들
    • ✓ 소매업체들은 판매활동의 수준, 교통흐름, 가시성 등을 고려

입지선택의 필요성 · 입지선택 의사결정 절차

p.9 – 10

입지선택의 필요성

  • 증가수요를 감당할 기존시설의 사업장 확장의 한계
  • 자원이나 원자재의 고갈
  • 특정지역의 사업지속비용의 상승
  • 수요지역의 변동 혹은 추가 → 원인: 인구변동, 국가 경쟁력 변화
  • 마케팅 전략의 일부로서 시장확대
    • → 예) 은행, 패스트푸드, 대형유통매장

입지선택 절차

  1. ① 입지 대안을 평가할 때 사용할 평가기준 결정
  2. ② 시장이나 원자재 공급업체의 위치 등 중요한 입지상황 요인들을 파악
  3. ③ 입지대안을 개발
    • a. 사업장이 위치할 하나 혹은 여러 국가들을 선택
    • b. 사업장이 위치할 국가 내의 지역이나 권역을 선택
    • c. 사업장이 위치할 지역이나 권역 내의 지역사회 대안들을 선택
    • d. 지역사회 대안들 중 부지나 구체적 위치 대안들을 후보지로 선택
  4. ④ 후보지들을 평가하고 선택

part 2입지선택 정량적 기법 — 1) 단일시설

단일시설의 입지선택을 위한 다수입지의 비교

p.11 – 12

1) 선호도 행렬방법의 입지선택 절차

  1. ① 주요 입지요인들을 결정하고 이들을 다시 주요인과 부요인으로 구분한다.
  2. ② 후보대안이 될 지역들을 특정수준으로 좁힌 후, 특정 지역 후보로 최종 선택한다.
  3. ③ 다양한 정보처로부터 자료 수집
  4. ④ 연간 수송비용이나 세금처럼 화폐가치로 측정되는 정량적 요인에 대해 자료를 분석
  5. ⑤ 정성적 요인 반영 후 가중점수가 가장 높은 입지를 선택

단일시설 중력모형 (부하-거리 점수 계산)

p.13 – 14
  • 부하-거리(ld) 점수를 최소로 하는 입지를 선택
\[ld = \textstyle\sum_i l_i \cdot d_i\]

여기서, 위치 \(i\)의 부하는 \(l_i\)이고,
위치 \(i\)의 직각거리는 \(d_i =\) \(|x_i - x^*| + |y_i - y^*|\) 이다.

[예제 6-2] 전기회사의 무게중심점 활용

고객위치납품량(X, Y) 좌표
아틀란타6,000(14, 4)
인디애나폴리스83,000(9, 13)
클리브랜드81,000(12, 11)
루이빌36,000(12, 8)
영스톤228,000(14, 12)
찰스톤17,000(15, 11)
리치몬드154,000(16, 6)
\(x^* =\) \(\dfrac{\sum_i l_i x_i}{\sum_i l_i} = \dfrac{8{,}276}{615}\) \(= 13.6\)
\(y^* =\) \(\dfrac{\sum_i l_i y_i}{\sum_i l_i} = \dfrac{6{,}179}{615}\) \(= 10.1\)
\(d_i = |x_i - x^*| + |y_i - y^*|\)
\(ld =\) \(\sum_i l_i d_i\) \(= 6(0.4+6.1) + 83(4.6+2.9) + 81(1.6+0.9) + 36(1.6+2.1)\)
\(+10(0.6+5.1) + 228(0.4+1.9) + 17(1.4+0.9) + 154(2.4+4.1) =\) 2658.5
무게중심이란\(x^*, y^*\) 는 부하(납품량, 천 단위)로 가중평균한 좌표예요. 부하-거리 점수가 작은 후보를 찾을 때 좋은 출발점이 돼요. (사이트 설명)
숫자 체크슬라이드 표에는 7곳 (합 605) 만 있지만, 합계 615 와 ld 식에는 납품량 10 (천) 인 지점이 하나 더 들어 있어요 — 좌표 (13, 5) 로 두면 Σl·x = 8,276, Σl·y = 6,179 가 정확히 맞아요. 또 8,276/615 ≈ 13.46 이라 반올림하면 13.5 지만 슬라이드는 13.6 으로 적었어요. 위 ld 식의 항들을 그대로 더하면 2,618.7 이고 (슬라이드 답은 2658.5), 반올림 없이 정확한 무게중심으로 계산하면 약 2,657 이에요. 시험에서는 슬라이드처럼 x* = 13.6, y* = 10.1 을 써서 풀면 돼요.

손익분기점(Break-even)분석의 활용

p.15 – 19
  • 대상후보 입지 별 고정비와 변동비를 구한다.
  • 모든 입지의 총비용(변동비와 고정비의 합)곡선을 그래프로 그린다.
  • 각 대안의 최저 비용 구간을 찾는다.
  • 최저 비용의 대안이 바뀌는 구역에 대해 대수적으로 손익분기점을 계산한다.

[예제 6-3] 입지의 손익분기점(Break-even)분석

새로운 공장의 입지선택 후보지 네 지역의 고정비와 변동비는 아래와 같다.

지역연간 고정비용단위당 변동비용
A$250,000$75
B$400,000$47
C$600,000$23
D$700,000$39
  • 문제 1) 네 지역의 총비용곡선을 하나의 그래프에 그려라. 각 대안의 비용이 가장 낮게 되는 구간을 산정하라.
  • 문제 2) 손익분기점 분석을 통해서 해당 구간의 손익분기점을 정하라. 수요기대치가 연간 15,000라면 최선의 입지는 어디인가?

풀이

Q=0, Q=15,000일 경우의 각 대안들의 총비용을 계산하여 선형적으로 직선을 긋는다.

지역고정비용변동비용총비용
A$250,000$75 × 15,000 =1,125,000$1,375,000
B$400,000$47 × 15,000 =705,000$1,105,000
C$600,000$23 × 15,000 =345,000$945,000
D$700,000$39 × 15,000 =585,000$1,285,000

A와 B지역의 손익분기점

\(\$250{,}000 + \$\)75\(Q = \$400{,}000 + \$47Q\)
\(Q = 5{,}357\)

B와 C지역의 손익분기점

\(\$400{,}000 + \$\)47\(Q = \$600{,}000 + \$23Q\)
\(Q = 8{,}333\)

(그림: 가로축 Q(천 개), 세로축 연간 총비용(천 달러) — Q=15에서 A 1,375 · D 1,285 · B 1,105 · C 945 / 구간 “A가 최선 · B가 최선 · C가 최선”)

위의 그림으로부터 기대수요 15,000일 경우 최적입지는 C지역이 최선임을 알 수 있다.

구간 정리Q < 5,357 → A · 5,357 < Q < 8,333 → B · Q > 8,333 → C. D 는 어느 구간에서도 최저가 아니에요.

복수시설 중력모형 (부하-거리 점수 계산)

p.20 – 27, 37 – 38

Case 1) 단일시설의 경우

  • \(i\) : 수요지; \(*\) : 단일시설
  • \(l_i\): 수요지 \(i\) 부하(수송량)
  • \(d_i = |x_i - x^*| + |y_i - y^*|\) : 수요지 \(i\)까지의 거리

만약, 복수시설의 입지결정으로 확장한다면 ???

복수시설의 경우 (수요지 중 복수시설 선택)

  • \(i\) : 시설; \(j\) : 수요지, 여기서, \(|i|>1\)
  • \(l_{ij}\): 시설 \(i\) 에서 수요지 \(j\) 로 운송되는 단위기간 당 부하(수송량)
  • \(d_{ij} = |x_i - x_j| + |y_i - y_j|\) : 시설 \(i\) 에서 수요지 \(j\)까지의 거리
\(ld_i =\) \(\displaystyle\sum_{j \in \min d_{ij}} l_{ij}\, d_{ij}\), \(i \;\;\Rightarrow\;\; Tld =\) \(\displaystyle\sum_i ld_i\)

P5 = {P5, P6, P7}		P4 권역: P1 29, P2 23, P3 12, P4 11 → Yes
P5 권역: P5 3, P6 5, P7 4 → Yes
⇒ 종료 (Tld = 11 + 3 = 14)

Note (p.27) — 이 경우, P1과 P4 및 P2와 P4의 경우에도 중심 도시가 되지만 각각의 총 수송 ton-km는 P1과 P4 = 0 + 25 = 25, P2와 P4 = 0 + 22 = 22 가 되어 P4와 P5의 경우보다 총 수송 ton-km가 크기 때문에 최적지점이라 할 수 없다.

왜 휴리스틱?지점 2개 고르는 경우를 모두 따져 보면 (위젯의 “전수 탐색”) 역시 P4, P5 가 최적 (14) 이에요. 하지만 지점이 많아지면 전수 탐색이 불가능해서 이런 반복 개선법을 써요.

복수시설 중력모형 — 정수계획 모형 (p.37 – 38)

<파라미터>

  • \(k\): 설치 시설의 수
  • \(m\): 시설 후보지의 수
  • \(n\): 시장 또는 수요지의 수
  • \(ld_{ij}\): 시설 \(i\)에서 수요지 \(j\)의 단위기간 당 거리-부하(수송량)

<의사결정변수>

  • \(y_i\): 시설 \(i\)가 물류센터로 선택된 경우 1, 패쇄된 경우 0
  • \(x_{ij}\): 시설 \(i\)가 수요지 \(j\)로 배송하는 경우 1, 그 외 경우 0
\[\text{Min}\;\; \sum_{i=1}^{m}\sum_{j=1}^{n} ld_{ij}\cdot x_{ij}\]
\[\begin{aligned} s.t.\;\; &\textstyle\sum_{j=1}^{n} x_{ij} \le m\cdot y_i && i = 1,\dots,m \\ &\textstyle\sum_{j=1}^{n} x_{ij} \ge y_i && i = 1,\dots,m \\ &\textstyle\sum_{i=1}^{m} x_{ij} \ge 1 && j = 1,\dots,n \\ &\textstyle\sum_{i=1}^{m} y_i = k \\ &x_{ij} = 0 \text{ or } 1,\;\; y_i = 0 \text{ or } 1 && i = 1,\dots,m;\; j = 1,\dots,n \end{aligned}\]
식 읽기첫 제약은 “선택되지 않은 시설 (yi = 0) 은 아무 수요지에도 배송 못 함”, 둘째는 “선택된 시설은 최소 1곳 (자기 자신) 에 배송”, 셋째는 “모든 수요지는 최소 한 시설에서 배송받음”, 넷째는 “시설은 정확히 k개”. 첫 제약의 상한은 슬라이드대로 m·yi 로 적었는데, 한 시설이 배송할 수 있는 수요지는 최대 n 곳이라 n·yi 로 써도 같은 역할이에요.

단일부품 복수시설 네트워크 최적화 입지선택 모델

p.28 – 34

<파라미터>

  • \(m\): 공장의 수
  • \(n\): 시장 또는 수요지의 수
  • \(D_j\): 시장 또는 수요지 \(j\)의 수요량
  • \(f_i\): 공장 \(i\)의 연간 생산능력
  • \(t_{ij}\): 공장 \(i\)에서 수요지 \(j\)의 연간 수송비용

<의사결정변수>

  • \(y_i\): 공장 \(i\)가 유지된 경우 1, 패쇄된 경우 0
  • \(x_{ij}\): 공장 \(i\)가 수요지 \(j\)로 매년 수송되는 양
\(\text{Min}\;\; \displaystyle\sum_{i=1}^{m}\) \(f_i \cdot y_i\) \(+ \displaystyle\sum_{i=1}^{m}\sum_{j=1}^{n}\) \(t_{ij} \cdot x_{ij}\)
\(s.t.\;\; \displaystyle\sum_{j=1}^{n} x_{ij} \le\) \(K_i \cdot y_i\) \(\qquad i = 1,\dots,m\)
\(\displaystyle\sum_{i=1}^{m} x_{ij} \ge\) \(D_j\) \(\qquad j = 1,\dots,n\)
\(x_{ij} \ge 0,\;\; y_i = 0 \text{ or } 1 \qquad i = 1,\dots,m;\; j = 1,\dots,n\)
기호 주의슬라이드 파라미터 목록은 \(f_i\) 를 “연간 생산능력” 으로만 정의했지만, 예제 6-4 의 목적함수 (7,650 yA + …) 에서는 고정비가, 제약식 (… ≤ 24 yB) 에서는 생산능력이 들어가요. 그래서 여기선 헷갈리지 않게 고정비 \(f_i\), 생산능력 \(K_i\) 로 나눠 적었어요. (슬라이드 목적함수 첫 Σ 의 상한도 n 으로 적혀 있지만 공장 수 m 이 맞아요.) 제약 \(\sum_j x_{ij} \le K_i y_i\) 가 “폐쇄된 공장은 아무것도 못 보낸다”를 만드는 핵심이에요.
