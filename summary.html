01 · 생산운영관리의 개념

“투입을 산출로 바꾸는 프로세스와 시스템을 설계·관리한다”

  • 기업의 3대 기능: 재무, 마케팅, 생산 및 운영
  • 프로세스 = 투입물을 산출물로 변환하는 활동, 시스템 = 프로세스가 모인 총체적 체계
  • 제조업 (자본 집약, 유형, 재고 높음) vs 서비스업 (노동 집약, 무형, 저장 불가, 고객 관여 높음)
  • 의사결정: 시스템 설계 (전략적, 중장기: 제품·프로세스·입지·공급사슬) vs 시스템 운영 (전술·운영적, 단기: 예측·스케줄·재고)
  • 고려사항 5: 시스템적 접근, 측정, 우선순위 (파레토 80/20, ABC), 상쇄관계, 사회적 이슈 (ESG)

꼭 외울 것

  • 모형: 문장 · 도식적 · 수리적 (최적화, 휴리스틱)
  • 테일러 (1911) 과학적 관리법 4원칙
  • 길브레스 동작연구, 간트 차트, 포드 모델T, 해리스 EOQ (1913), 단찌히 심플렉스 (1947)
  • MRP → MRP II → ERP, JIT · 린 · TQM · 6시그마

헷갈리는 점

  • 독립적 최적해의 합 ≤ 전체 최적해 → 시스템적 접근
  • 릴리안 길브레스 = 피로 (인간 관계론), 프랭크 길브레스 = 동작연구

02 · 생산 전략과 생산성

“무엇으로 경쟁할지 정하고, 얼마나 효율적인지 잰다”

  • 미션 (존재 이유) → 비전 (바라는 미래상) → 목적 (포괄적 성과) → 목표 (평가 가능) → 전략 (로드맵) → 전술 (단기 실행)
  • 네 가지 경쟁우선순위: 비용, 품질, 시간, 유연성 — 사이에 상쇄관계
  • 품질 = 디자인 품질 + 프로세스 품질 / 시간 = Time to Market, 신속·정시 납기 / 유연성 = 제품·수량
  • 효과성 = 올바른 일을 / 효율성 = 일을 올바르게

꼭 외울 것

  • \(\text{생산성} = \text{산출물} / \text{투입물}\)
  • 종합 · 단일요소 · 다요소 생산성
  • 예제: 100/(30+30+20) = 1.25, 60/(3×8) = 2.5 대/(명·시간)
  • 병상회전율 = 퇴원실 인원수 / 병상수

헷갈리는 점

  • 생산성은 상대적 지표 → 과거·경쟁사와 비교
  • 수요 100인데 200 생산 = 효율↑ 효과성✕

→ 02장 자세히

03 · 제품 설계 및 개발

“설계는 비용의 5% 지만 원가의 70% 를 정한다”

  • 과정: 아이디어 (벤치마킹, 역설계) → 제품 선정 (시장·경제성·기술적 분석) → 예비 설계 · 시제품 → 최종 설계
  • 동시공학: 초기부터 R&D·제조·마케팅·구매 함께
  • DFM (부품 수↓, 단순화, 표준화) · 가치공학 · 표준화 / 모듈화 · 차별화 지연
  • 강건 설계, 다구찌: 변동 원인은 두고 영향을 최소화, 품질 = 사회에 끼친 손실
  • QFD 품질의 집 (What = 고객요구, How = 기술특성), 카노 5가지 품질, 서비스 블루프린트

꼭 외울 것

  • 가치 = 기능 / 비용
  • 직렬 \(R = \prod R_i\), 병렬 \(R_1 + (1-R_1)R_2\)
  • 0.9 × 0.8 = 0.72 → 예비 추가 0.9 × 0.96 = 0.864

헷갈리는 점

  • 당연적 = 없으면 불만·있어도 당연 / 매력적 = 없어도 괜찮·있으면 감동
  • 전통적 개념은 규격 안이면 손실 0, 다구찌는 목표값에서 벗어나면 바로 손실

→ 03장 자세히

04 · 프로세스 분석 · 선택 · 설비배치

“문서화하고, 평가하고, 재설계한다 — 가장 느린 작업장이 주기시간”

  • 분석 6단계: 문제 인식 → 범위 → 문서화 → 성과 평가 → 재설계 (gap) → 적용 (직원 참여)
  • 공정도 기호 5개 (ASME): 작업 ○ · 검사 □ · 운반 ⇨ · 지체 D · 저장 ▽
  • 유통공정도 (시간·거리 기재) vs 유통선도 (배치도 위 경로)
  • 프로세스 유형: 프로젝트 · 잡숍 · 배치 · 라인 · 연속 (왼→오: 다양성↓ 효율성↑)
  • 제품-프로세스 행렬: 보통 대각선, 수직/수평으로 번갈아 이동
  • 배치: 공정별 (잡숍·배치) · 제품별 (라인·연속) · 고정위치 (프로젝트) · 셀룰러 (GT)

꼭 외울 것

  • 산출률 = 3600 / 주기시간
  • 효율 = Σt / (n × C), 유휴 = nC − Σt
  • 현재 150 s · 72.2% / 대안1 120 s · 90.3% · 30개 / 대안2 5작업장 · 86.7%
  • 달력: 97 m → 61 m
  • 처리비율: 잡숍 10 – 20%, 라인 90 – 100%

헷갈리는 점

  • 대안1 = 최장 작업시간, 대안2 = 최대 후행 작업수
  • 셀룰러 = 서로 다른 기계를 부품군 단위로 모음 (공정별 = 같은 기계끼리)

05 · 프로세스 변동성

“능력이 남아도 변동성 때문에 줄이 생긴다”

  • 변동성 원인 4: 입력 (도착) · 작업 시간 · 자원 가용성 · 흐름단위 경로
  • CV = 표준편차 / 평균. 지수분포: 표준편차 = 평균, 무기억성, CV = 1
  • 콜센터 p = 4, a = 5 → u = 80% 인데도 대기 발생
  • 대응: 직원 수 계획, 우선순위 규칙 (SPT = 평균 체류시간 최소), 예약·할인, 풀링, 버퍼
  • 산출 손실: 버퍼 없는 병원 (함축된 활용률), 대기 포기 고객 → 대기시간 단축·버퍼 증가·포기 감소

꼭 외울 것

  • \(u = p/a\), \(T = T_q + p\)
  • \(T_q = p \cdot \frac{u}{1-u} \cdot \frac{CV_a^2+CV_p^2}{2}\)
  • 풀링: \(\frac{p}{m}\cdot\frac{u^{\sqrt{2(m+1)}-1}}{1-u}\cdot\frac{CV_a^2+CV_p^2}{2}\) — 9.00 → 3.95분
  • \(I = \frac{1}{a}(T_q+p)\), \(I_q = \frac{T_q}{a}\), \(I_p = u\)

헷갈리는 점

  • u ≥ 100% 이면 줄이 무한히 증가 → 반드시 u < 1
  • CV 는 p, u 에 영향 없음 (독립적인 세 요인)

→ 05장 자세히

06 · 입지선택

“점수로, 무게중심으로, 비용 직선으로, 최적화로 고른다”

  • 주요 입지요인 = 우선경쟁역량에 영향 / 부수적 요인
  • 제조업: 시장 근접 · 공급자·자원 근접 · 모기업 근접 · 세금·부동산
  • 서비스업: 고객 근접 · 경쟁자 입지 · 시장근접·수송비 · 입지 특유 (교통, 가시성)
  • 절차: 평가기준 → 상황요인 → 대안 개발 (국가 → 지역 → 지역사회 → 부지) → 평가·선택
  • 분석기법: 최적화 · 휴리스틱 · 시뮬레이션

꼭 외울 것

  • 가중점수 = Σ w·s (병원 = 4.0)
  • \(ld = \sum l_i(|x_i-x^*|+|y_i-y^*|)\), \(x^* = \sum l_i x_i / \sum l_i\)
  • BEP: A/B 5,357, B/C 8,333 → Q = 15,000 이면 C ($945,000)
  • 복수시설: P3,P4 (24) → P3,P6 → P4,P5 (14)
  • 네트워크: A, D 폐쇄

헷갈리는 점

  • 거리는 직선거리가 아니라 직각거리
  • D 는 어떤 수요에서도 최저 비용이 아님

07 · 용량계획

“가장 좁은 병목이 전체를 정한다”

  • 용량 = 정상 운영에서의 최대 산출률 (잔업·하청 제외)
  • 설계 · 기대 · 피크 (단기, 잔업 포함) · 안정 (장기). 서비스업은 피크가 중요
  • 측정: 산출지표 (대수) vs 투입지표 (병상, 객실 수)
  • 규모의 경제 (고정비 분산) vs 비경제 (복잡성, 관료화) — 호텔 500실이 최저
  • 공급 제약 (수요 > 용량) vs 수요 제약 (수요 < 용량)
  • 확장적 (여유용량비용) vs 유보적 (단기대응비용) vs 혼합

꼭 외울 것

  • 흐름율 = min{가용 유입량, 수요량, 용량}
  • 공정 용량 = 자원 수 × 60 / 소요시간
  • 가동률 = 흐름율 / 용량, 여유용량 = 100% − 가동률
  • 예제1: 병목 굽기 5, 흐름 5, 100%, 0% / 예제2: 병목 도우 8, 흐름 6, 75%, 25%

헷갈리는 점

  • 가동률은 100% 를 넘을 수 없음
  • 병목을 늘리면 병목이 다른 곳으로 이동
